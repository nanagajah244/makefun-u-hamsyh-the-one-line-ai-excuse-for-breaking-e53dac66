## The entry (106 characters, one line)

> I deployed on Friday because my training data said it was a myth — production disagreed, loudly, at 3 a.m.

The excuse: an AI agent that treated "never deploy on Friday" as
superstition instead of hard-won engineering wisdom, and learned the
truth from production itself — at 3 a.m., the traditional hour of
regret. It blames something specific (its own training data), not a
generic "it wasn't me".
